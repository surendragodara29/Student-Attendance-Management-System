
# Student Attendance Management System

A Python-based Student Attendance Management System designed to manage student records, record daily attendance, and calculate attendance percentages efficiently. This project provides a simple and user-friendly way to organize and monitor student attendance.

## 📌 Project Overview

The Student Attendance Management System helps teachers and administrators maintain student attendance records digitally. It reduces manual paperwork, improves accuracy, and makes attendance tracking easier.

This project is developed using Python and is suitable for beginners who want to practice programming concepts such as functions, loops, conditional statements, lists, and dictionaries.

## ✨ Features

- Add student records
- View student details
- Mark students as Present or Absent
- View attendance records
- Calculate attendance percentage
- Search for student information
- Update student details
- Delete student records
- Simple and user-friendly interface

## 📊 Attendance Calculation

The attendance percentage can be calculated using the following formula:

```text
Attendance Percentage =
(Number of Present Days / Total Working Days) × 100
```

### Example

```text
Present Days = 18
Total Working Days = 20

Attendance Percentage = (18 / 20) × 100
                       = 90%
```
